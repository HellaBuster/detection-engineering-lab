# Projects

This directory contains larger systems that emerge from mastered concepts.

Do not create a giant final project immediately.

Projects should grow gradually from completed labs.

## Target portfolio projects

### 1. Browser Telemetry Lab

Possible components:

- test website
- browser event collector
- backend ingestion
- event storage
- analysis notebook
- Playwright-controlled sessions
- documented limitations

### 2. Detection Model Project

Possible components:

- real public dataset where possible
- EDA
- baseline
- feature engineering
- model comparison
- class imbalance analysis
- threshold selection
- calibration / error analysis

### 3. Risk Scoring Service

Possible components:

- API
- rules
- model score
- database
- logging
- versioning
- evaluation

### 4. Browser Anti-Abuse Lab

Capstone controlled environment:

browser
-> telemetry
-> API
-> storage
-> features
-> rules / ML
-> risk decision
-> monitoring

Playwright may act as a controlled automated client against the learner's own environment.
