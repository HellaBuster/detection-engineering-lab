# Datasets

## `real/`

Use only datasets that are public, permitted, and suitable for repository publication.

Each real dataset should have a companion metadata file describing:

- source
- access date
- license or usage note if known
- schema
- limitations
- whether the raw file may legally be committed

Large or restricted datasets should not be committed directly. Store retrieval instructions or metadata instead.

## `synthetic/`

Synthetic data is allowed only when justified.

Each synthetic dataset must document:

- why real data was unsuitable;
- which properties were simulated;
- which conclusions may not generalize.
