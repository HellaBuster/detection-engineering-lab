# Decisions

## Learning interface

The physical notebook and pen are the primary thinking tools.

## Information access

The learner should not need to independently search the web for educational material.

The AI agent researches current information when necessary and teaches it inside the chat.

## Progression

The AI evaluator controls mastery gates.

The learner cannot self-approve or force progression.

## Coding

AI-assisted coding is allowed and expected.

Manual typing volume is not the learning objective.

Code must still be conceptually understood.

## Real-world preference

Use real-world data, permitted websites/APIs, own logs, and controlled open-source systems whenever suitable.

Synthetic data is a fallback, not the default.

## Career direction

Primary direction:

Detection Engineering / Anti-Abuse / Fraud Detection

with strong foundations in:

- ML / data
- browser systems
- networking
- automation
- production engineering

## Public repository

This repository is intended to remain public and become part of the learner's portfolio.

Avoid secrets, private credentials, personal data, or proprietary datasets.

## Source of truth

Repository state + completed evidence + physical notebook.

Chat history alone is not authoritative.
