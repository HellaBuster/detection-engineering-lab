# Session Protocol

## Start

The AI reads repository state before teaching.

Then it gives only the minimum recap required to continue.

## Default flow

1. Recall
2. New concept
3. В тетрадь
4. Prediction
5. Lab
6. Observation
7. Explanation
8. Transfer task
9. Mastery evaluation
10. State update

## Topic size

Prefer one deeply understood idea over five shallow ideas.

## End gate

Every required topic ends in one of:

### PASSED
Evidence is sufficient.
Update records and unlock the next dependency.

### PROVISIONAL
Understanding exists, but evidence is incomplete.
Do not advance.
Assign one focused remediation task.

### NEEDS_REVIEW
A prerequisite model is broken.
Return to the smallest necessary prerequisite.

## Progression language

Do not ask:

> Хочешь дальше?

Instead decide:

> Gate passed. Next topic is unlocked.

or:

> Gate not passed. One criterion remains.
