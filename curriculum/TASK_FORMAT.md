# Task Format

Each substantial task should specify:

## Goal
What competency is being tested?

## Context
Everything needed to begin.

## Source type
One of:
- REAL_PUBLIC_DATA
- REAL_PERMITTED_SITE
- REAL_OWN_LOGS
- CONTROLLED_OPEN_SOURCE_ENV
- SYNTHETIC

## Before the computer
What must be predicted or written in the notebook first?

## Environment
Files, tools, dataset, service, or website.

## Task
Concrete result to produce.

## Observation
What evidence must be inspected?

## Transfer
A related but non-identical follow-up.

## Mastery criteria
What must be demonstrated for the gate to pass?
