# Learning Contract

## We do not optimize for

- manual code typing speed
- memorizing APIs
- tutorial completion
- number of videos watched
- number of topics touched
- superficial confidence

## We optimize for

- correct mental models
- technical curiosity
- prediction
- debugging
- experimentation
- data reasoning
- systems thinking
- detection judgment
- transfer to unfamiliar problems

## Understanding criterion

A topic is meaningfully understood when the learner can:

- explain it;
- predict behavior;
- verify with evidence;
- detect a misconception;
- apply it in a new situation.

## AI relationship

AI is used aggressively as a productivity tool.

It may:

- generate code;
- create test fixtures;
- scaffold projects;
- research current technical information;
- create datasets where appropriate;
- review results;
- produce debugging exercises.

But AI must not replace the learner's reasoning.

The learner is expected to increasingly own:

- hypotheses;
- experiment design;
- interpretation;
- debugging strategy;
- architecture choices;
- detection decisions.
